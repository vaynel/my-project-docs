## Brand & Style
The design system is engineered for the high-stakes environment of automated financial trading. It prioritizes clarity, speed of cognition, and a sense of calm reliability. The brand personality is **professional** and **growth-oriented**, designed to instill a sense of optimistic control in the user as they monitor their automated strategies.

The visual style is **Minimalist-Modern**. It leverages heavy whitespace to reduce cognitive load during data-heavy sessions. By removing unnecessary ornamentation, the system directs the user's focus toward critical performance metrics and system health indicators. The interface evokes the precision of a high-end medical or aerospace instrument—utilitarian yet refined.

## Colors
The palette is rooted in financial semantics. The **Primary "Growth Green"** is used for primary actions and positive momentum indicators, symbolizing profit and upward trends. **Trust Blue** serves as the secondary color, used for system-level notifications, navigation, and neutral interactive elements to provide a professional balance.

- **Backgrounds:** Use a crisp white (#FFFFFF) for cards and a soft "Slate" gray (#F8FAFC) for the application background to create subtle separation.
- **Data Visualization:** Profit uses a vibrant emerald, while losses use a high-contrast coral red. Neutral or "at-par" states use a medium gray.
- **Accessibility:** All text-on-background combinations must maintain a minimum 4.5:1 contrast ratio to ensure readability under various lighting conditions common for home server monitoring.

## Typography
The typography strategy distinguishes between **Brand/Overview** and **Data/Execution**. 

- **Hanken Grotesk** is used for headlines and summary metrics, providing a sharp, contemporary professional look.
- **Inter** handles all body copy and UI labels, chosen for its exceptional legibility and neutral systematic feel.
- **JetBrains Mono** is reserved for price action, ticker symbols, and numerical data in tables. This monospaced font ensures that digits align vertically in lists, allowing the eye to scan for changes in magnitude instantly.

Scale down large headlines on mobile to prevent text wrapping in tight dashboard widgets.

## Layout & Spacing
This design system utilizes a **Fluid Grid** with a 12-column structure for desktop. To maintain high visibility, the layout prioritizes a "Density-on-Demand" approach: high-level dashboards use generous padding (24px+), while detailed trade logs and data tables use a tighter 8px-12px rhythm.

- **Desktop:** 12 columns, 24px gutters, 40px side margins.
- **Tablet:** 8 columns, 16px gutters, 24px side margins.
- **Mobile:** 4 columns, 12px gutters, 16px side margins.

Content should be organized into modular "widgets" or "cards" that can reflow. For financial data, prioritize horizontal scanning in tables; never truncate price data.

## Elevation & Depth
To maintain a clean and minimalist aesthetic, this design system avoids heavy shadows. Hierarchy is established through **Tonal Layers** and **Low-Contrast Outlines**.

- **Level 0 (Background):** #F8FAFC (Slate).
- **Level 1 (Cards/Widgets):** White background with a 1px border in #E2E8F0. No shadow.
- **Level 2 (Hover/Active):** Subtle 4px blur shadow with 5% opacity and a tinted color of the primary green to indicate interactivity.
- **Overlays (Modals):** A heavy 16px backdrop blur (Glassmorphism) is used for the background dimming to keep the user’s focus on the execution window without losing the context of the real-time charts behind it.

## Shapes
The shape language is **Soft (0.25rem)**. This provides a professional, "to-the-point" feel that is slightly friendlier than sharp corners but more serious than highly rounded "bubbly" designs. 

- **Standard Elements:** 4px radius (Inputs, Buttons, Cards).
- **Status Pills:** Fully rounded (Pill-shaped) to distinguish them from interactive buttons.
- **Charts:** Line charts should use a slight 2px curve (interpolation) to feel modern rather than jagged, but not so much as to obscure the actual data points.

## Components
### Buttons
- **Primary:** Solid "Growth Green" with white text. Used for "Execute Trade" or "Start Bot."
- **Secondary:** Outline "Trust Blue" for "Settings" or "View Logs."
- **Ghost:** Transparent background with Slate text for low-priority actions.

### Data Tables
- Header rows must be sticky with a subtle gray background. 
- Use alternating row stripes (zebra striping) only when data exceeds 10 rows.
- Price columns must use monospaced fonts and be right-aligned.

### Status Indicators
- Use a "Pulse" animation (a soft glowing ring) for "Live" or "Active Trading" states.
- Status chips use a low-opacity background of the status color (e.g., 10% green) with high-opacity text for maximum legibility.

### Real-time Charts
- Use a 2px stroke width for primary trend lines. 
- Area charts should use a very light gradient fade (primary color to transparent) to emphasize volume without cluttering the grid lines.

### Input Fields
- Use "Focus-Visible" states with a 2px Trust Blue outline to ensure the user knows exactly where they are about to type trade parameters.
